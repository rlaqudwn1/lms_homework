## 관찰된 패턴 요약 (합성은 여기까지)

1. **백로그 실증 어휘 = "사놓고 안 한 게임"·"유기했음"·"하다가 말았음"·"손도 안 댐"** — "숙제"는 MMO 일일과제 뜻이라 오용 위험, "스팀 창고"는 실사용 미확인.
2. **결정 변수는 육성에서 구체물로 나온다:** 플탐·멀미·예산 한도·같이할 사람·"정가 주고 산 겜 vs 찍먹" — 추상어("취향", "기분")가 아니라 물성 있는 조건.
3. **추천 어투 공식 = "[장르/경험] 좋아하면 + 무조건 해라/강추" 2절 구조** + 리스크 완화 단서("데모 있으니까 해보고 결정하셈"), 종결 -임/-함/-셈/-해라.
4. **리뷰 어투는 증거-압축형:** 플레이 시간이 곧 증거("제 플탐을 보셈"), 시간 손실 자학 유머("잠깐 했는데 아침임"), 극단 축약("갓겜").
5. **국내 데이터-제품 UI = 해요체 + 데이터 근거 선행("7.5억 개의 별점 데이터를 바탕으로") + 행동↔정확도 교환 프레임("평가를 많이 할수록 정확해져요")**, Steam은 1인칭 "내가 ~하는" 라벨 — 커뮤니티 해라체와 온도차 큼 → 어디서 어느 톤을 쓸지는 배치 결정 사안.

## 미해결 → 사람에게 (카피 결정 사안)

- 랜딩 기본 종결어미: 커뮤니티 해라체(-임/-셈)를 어디까지 vs 서비스 해요체 — 섹션별 혼용 여부는 작가·검수 판단.
- "숙제"·"스팀 창고" 어휘 채택 여부 — 실사용 근거 부족, 쓰려면 추가 검증 또는 폐기.
- 비속어 섞인 육성("존나", "씹혜자")의 순화 수위.
- 결정 마비 직접 진술이 얇다(2건) — Job문장을 이 코퍼스만으로 확정하지 말 것.
