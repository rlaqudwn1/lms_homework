## 0. 무엇을 번역하는가 (제품 → 디자인)
- 제품 한 문장: **Steam URL 하나 → ①설명가능한 백로그 추천(Trust) + ②공유가능한 게이밍 정체성(Aha).**
- 감정 곡선 = 랜딩 세로 구조: **호기심 → receipts("이게 나네, 숫자로 증명") → 신뢰(근거 붙은 추천) → 공유욕.**
- 차별화(해자) = backloggd에 **없는 두 레이어**: 근거(Trust) + 정체성(Aha). → 디자인도 이 둘을 *주인공*으로.
- 비타협 규율: **바넘 금지, 모든 주장은 숫자에 묶는다.** → 카피·수치 컴포넌트의 설계 제약.
- 레지스터 3종(확정): **데이터-신뢰 · 에디토리얼 · 공유 카드** (게이머 네온 에너지는 의도적 제외).

## 1. 미학 결정 — "쿨 블루-잉크 무대" (왜)
세 레퍼런스의 다크가 갈린다: backloggd=네이비-잉크+블루화이트 텍스트, stats-fm=순수 무채 근흑+순백. **초안은 backloggd 계열의 쿨 블루-잉크를 채택**한다.
- **왜:** 이 제품의 콘텐츠(게임 커버아트)는 따뜻하고 채도 높다. 무대를 **차가운 네이비-잉크**로 깔면 따뜻한 커버가 더 튀고("UI는 극장, 색은 콘텐츠"), 순백 대신 **차가운 블루-화이트 텍스트**가 브랜드 온도를 만든다(순수 무채보다 정체성이 선다).
- 절제 강도는 stats-fm에서 배운다: **무채 무대 + 텍스트 + 액센트**로 UI 자체는 색을 최소화. 다색은 콘텐츠(커버)와 액센트에만.

## 2. 컬러 (6 토큰)
쿨 잉크 표면 3단 + 블루-화이트 텍스트 2단 + **액센트 2개**(쿨=Trust, 웜=Aha). 액센트 2개는 규율 위반이 아니라 **두 레이어 차별화의 시각적 코드**다 — 쿨은 "근거/인사이트", 웜은 "정체성/트로피".

| 역할 | hex | 용도 |
|---|---|---|
| `surface/ink` | `#0F131A` | 최심부 배경(무대). 차가운 네이비-블랙 |
| `surface/raised` | `#191F2A` | 카드·패널·섹션 교차 |
| `surface/edge` | `#2B3342` | 보더·필드·divider (얇게) |
| `text/primary` | `#D8E4F5` | 헤딩·본문. **차가운 블루-화이트**(순백 아님) |
| `text/secondary` | `#8593A6` | 라벨·메타·캡션·근거 보조문 |
| `accent/insight` | `#7C93FF` | **쿨 액센트(Trust)** — CTA·링크·포커스·라이브 델타·추천 근거 하이라이트·정체성 카드 글로우 |
| `accent/trophy` | `#FFC24B` | **웜 액센트(Aha) — 제한적** — receipts 거대 숫자·성취/트로피·정체성 카드의 웜 포인트에만 |

- 절제 규칙: `accent/trophy`(웜)는 **숫자 receipts·정체성 카드에만**. 나머지 강조는 전부 `accent/insight`(쿨) 하나로. UI 구조/버튼/텍스트는 무채+쿨.
- (앱에서 승계) 상태별 다색 시스템(완료/플레이/위시…)은 **랜딩엔 안 끌어옴** — 랜딩은 마케팅 무대, 다색은 커버아트에 양보.

## 3. 타이포 (역할 시스템)
2-페이스 + 의도된 굵기 대비. **에디토리얼 헤드라인은 크되 가볍게**(ramp에서 배움: 확신은 굵기 아닌 크기·여백), **receipts 숫자는 무겁게**(backloggd: 트로피 숫자). 이 긴장이 "에디토리얼 ↔ 데이터" 레지스터를 한 화면에 공존시킨다.

- `type/display` (에디토리얼 헤드라인): 모던 그로테스크, **대형·light~regular**(예: General Sans / Geist / Inter Display, weight 400–500). 히어로 48–64px, 섹션 32–40px, line-height 타이트(1.0–1.1).
- `type/body`: 동일 계열 산세리프 16px / 450–500, LH 24, `text/secondary`. (backloggd Roboto의 중립성 계승)
- `type/numeral` (**receipts 트로피 숫자**): heavy(700–800), **tabular**, **선행 0 유지**(예 `1049 / 068 / 040` — backloggd 시그니처), 색 `accent/trophy`. 거대(56–96px). 자릿수 자체가 스펙터클(stats-fm 라이브 숫자 계승).
- `type/label` (유틸/라벨/근거 태그): 13–14px, `text/secondary`, 필요시 **전대문자 트래킹**(ramp의 회계-라벨 톤 — "근거"에 감사(監査)적 신뢰감).
- 굵기 정책: ≤300 얇은 웨이트는 헤드라인 대형에서만. 라벨·숫자는 절대 얇게 안 감(stats-fm 볼드-포워드 부분 계승).

## 4. 레이아웃 (감정 곡선 = 세로 구조)
쿨 잉크 무대, max-width ≈1200px, 넉넉한 섹션 세로 여백(공기 많음). 섹션은 `ink ↔ raised` 미세 명도 교차로 구분(보더 최소).

1. **호기심 — 히어로**: 단일 액션 = **"Steam URL 붙여넣기" 입력 필드 + 쿨 CTA**. 그 옆/뒤에 **발광하는 정체성 카드**(Aha 티저)가 잉크 무대 위에 떠 있음. 리드 = *글로우 카드 + 한 줄 입력*. (backloggd 커버-모자이크 히어로 + stats-fm 기울인 카드 아트의 교배)
2. **receipts — "이게 나네"**: 거대 트로피 숫자(웜, 선행0) + 취향 히스토그램(쿨 글로우). "너의 게이밍 정체성, 숫자로." **바넘 금지 → 전부 실측치에 묶임**(backloggd 프로필 receipts + game-detail 히스토그램 계승).
3. **신뢰 — 근거 붙은 추천(해자)**: 추천 카드 각각에 **"왜"가 붙는다** — [커버] + [한 줄 근거: "네가 100% 클리어한 소울류 3편 때문에"]. 근거 텍스트에 쿨 액센트 태그. backloggd엔 없는 레이어 = 여기가 차별화의 심장.
4. **공유욕 — 공유 카드**: 히어로의 정체성 카드가 **내보내기 가능한 공유 카드**로 재등장(stats-fm 공유 정체성 카드 계승). 페이지를 카드로 열고 카드로 닫음(북엔드).
5. **라이브 티커(ramp 모티프)**: 하단 고정 띠 — "N개 정체성 생성됨 · M개 게임 분석됨" 다크 무대 버전, 쿨 액센트 카운트업. 라이트/옐로는 버리고 구조만 이식.
- 반응형/품질 하한: 2컬럼→세로 스택, 커버 그리드 열 축소, 키보드 포커스링(쿨 액센트), `prefers-reduced-motion` 존중.

## 5. ★ 시그니처 (1개) — 발광하는 정체성 카드  🔴 v0.4에서 폐기 → 취향 아틀라스
**The Glowing Identity Card.** 잉크 무대 위에 뜬 다크 카드인데, **내용물(게임 커버아트)이 스스로 빛나고**, 가장자리에 쿨 액센트 글로우, 안에는 웜 트로피 숫자(선행0)와 취향 요약이 담긴다.
- 이걸 빼면 이 랜딩이 아니게 된다: 제품의 두 레이어(정체성 Aha=카드 그 자체, 근거 Trust=카드가 숫자·이유로 뒷받침됨)를 **하나의 오브젝트**로 응축.
- 등장: **히어로 티저 → 공유 섹션 페이오프**로 북엔드. 호기심의 미끼이자 공유욕의 산출물.
- 글로우 = 이 페이지의 유일한 "빛". 나머지 UI는 flat·무채. (stats-fm 폰 목업 부양 + backloggd 커버 발광 + ramp 확신형 숫자의 합)
