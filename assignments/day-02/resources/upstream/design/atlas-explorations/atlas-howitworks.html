003 · Taste Atlas · 생성 파이프라인 (어떻게 작동하나)

데이터는 어떻게 대륙이 되나 — 실제로 돌려본 5단계

추천했던 방식(고정 인접 그래프 + 약한 노이즈 + 3레버)을 진짜 코드로 구현해서 단계별로 렌더했어요. 예시 스팀 라이브러리(12장르, 보유량·정복도 예시값)가 입력이고, 오른쪽 끝이 결과물입니다. 손으로 배치한 게 아니라 규칙이 만든 지도 — 그래서 생성기(Claude Design/Pencil)에 규칙만 넘기면 재현돼요.

파이프라인 데이터 → 대륙, 다섯 걸음

각 단계에서 무엇이 들어가는지(데이터 레버 / 삽화 레버) 표시했어요. 같은 12장르가 왼→오로 변형됩니다.

1

입력 데이터

장르별 보유량·정복도. 그냥 숫자.

데이터
2

인접 그래프

유사 장르를 선으로 연결. 어느 땅이 붙을지 고정.

유사도
3

씨앗 배치

그래프를 지도 좌표로 이완. 연결된 장르가 이웃이 됨.

넓이=보유
4

성장 + 노이즈

씨앗이 자라 겹치며 한 대륙으로. 약한 노이즈가 해안을 유기적으로.

지형
5

색·고도·모티프

밝기=정복도, 변방=미개척, 픽셀 모티프로 장르 인식.

삽화

결과 완성된 취향 대륙 — 3레버가 지형으로

5단계의 결과를 크게. 심장부는 넓이의 창발(제일 넓은 땅이 가운데)이라 따로 안 넣어도 생겨요.

읽는 법 — 넓이=보유·플레이시간 · 밝기=정복도(밝을수록 마스터) · 보라 변방=미개척(다음 개척지) · 중앙 대형 = 심장부(핵심 취향, 창발) · 모티프=장르. 웜 색 0, 쿨 단일.

왜 고정? "매번 같은 지도"라야 신뢰가 산다

추천했던 열린결정 #2(절차생성 강도)를 눈으로. 왼쪽=우리 방식, 오른쪽=순수 절차생성.

✅ 고정 그래프 + 약한 노이즈 (추천)

같은 라이브러리 → 항상 같은 대륙. 내일 다시 봐도 내 지형이 그대로 → "이게 내 세계"가 성립.

// 3번 렌더 — 픽셀 단위로 동일

❌ 순수 절차생성

매번 다른 지도. 예뻐도 "내 것"이 안 됨 — 새로고침마다 취향 지형이 바뀌면 신뢰가 깨짐.

// 3번 렌더 — 제각각

진화 당신의 대륙은 자란다 — 계정이 발전하면

고정 그래프라 자리·이웃은 그대로(정체성 유지). 데이터가 자라면 크기·밝기만 자라고, 미개척 변방이 개척지로 바뀐다. 결정론 = 정지가 아니라 안정적 진화.

지금
→
3개월 뒤 · 더 플레이·더 정복

바뀐 것: 소울라이크 ↑넓어짐·↑밝아짐(더 사고 더 깸) · 대전격투 곶 ↑성장(더 플레이) · 시뮬 보라→teal 개척 시작(미개척→탐험).  안 바뀐 것: 대륙 실루엣·각 땅의 자리·이웃 → 그래서 여전히 "내 대륙".

범례 정복(밝음) 탐험 중 거의 안 함(어두움) 미개척 변방 · 심볼 = 장르 · 격자 = 탐험 좌표

이게 "어떻게 한건지"예요. 이대로면 옵션 A(biome 사전 + 인접 그래프 스펙) 착수할게요 — 이 파이프라인의 ②③⑤를 규칙서로 옮기는 일이에요.
