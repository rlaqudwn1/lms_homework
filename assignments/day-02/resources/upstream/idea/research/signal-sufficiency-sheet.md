# 신호 충분성 시트 — next-save (사람 0명 검증 도구)

> **이 문서의 정체:** red-team 5개 kill-가정 중 **#1(신호 충분성)·#2(moat)·#5(근거 인상)** 를 *시트 하나로 동시에* 판정하는 실물 검증 도구. 계획은 [`redteam-response-plan.md`](./redteam-response-plan.md), 신호 정의는 [`player-typology.md`](./player-typology.md), 제품 맥락은 [`../ideas/next-save.md`](../ideas/next-save.md) §7.
> **날짜:** 2026-07-08 · **상태:** 🟩 틀 완성 / ⬜ 실제 프로필 미투입.
> **왜 사람 0명:** 필요한 건 **공개 Steam 프로필**뿐. 수요("사람들이 원하나")가 아니라 **"기술이 인상적·정직한가"** 를 재는 도구라 인적자원 불필요.

## 0. 이 시트가 답하는 질문 (판정 3종)

각 프로필을 채우면 아래 셋이 한 번에 판정된다:

| 판정 | 질문 | 통과 = | 실패 = |
|---|---|---|---|
| **#1 신호 충분성** | 프로필 하나로 **뻔하지 않은** 페르소나가 나오나? | 라벨이 이 사람을 실제로 짚음 | 아무한테나 맞는 라벨 |
| **#2 moat(차별)** | 그 해석이 **HLTB/SteamDB가 못 하는** 것인가? | "너 기준" 해석이 게임단위 평균을 넘음 | '느린 HLTB'(그냥 평균 재탕) |
| **#5 근거 인상** | 근거가 **if문/설명극장**이 아닌가? | 신호를 인용하고 신호를 안 넘음 | 데이터에 없는 걸 지어냄 |

**KILL 기준:** 채운 프로필의 **절반 이상**에서 "뻔함" 또는 "틀림"이 나오면 → **wedge(설명충실성+정체성) 재검토.** 통과 = 포트폴리오 알맹이 실재 증명. 실패 = *개발 전에* 알아서 다행.

## 1. 입력 신호 — 무엇을, 어디서 (공개, 로그인 불필요)

**분류에 쓰는 player-level 5신호 (본인 프로필 = 성향):**

| # | 신호 | 뽑는 법 (공개 프로필) | 정규화 |
|---|---|---|---|
| S1 | **게임별 플레이타임** | 프로필 → Games 탭 (공개 시 게임별 시간 노출). API: `GetOwnedGames(include_played_free_games)` | 시간(h) 벡터 |
| S2 | **본인 도전과제 달성%** | 게임별 Achievements 페이지 = 내가 딴 것/전체. API: `GetPlayerAchievements` | 게임별 % → **중앙값** |
| S3 | **장르 집중도** | 보유 게임 appid → 스토어 장르/태그 매핑 → 시간가중 분포 | 상위장르 시간비중 (%) |
| S4 | **멀티플레이 시간 비중** | 멀티/PvP 태그 게임 시간 합 / 총 시간 | % |
| S5 | **보유 vs 플레이 격차** | 0시간 보유 게임 수 / 총 보유 수 (= 백로그율) | % + 보유수 |

**해석에만 쓰는 game-level 데이터 (⚠️ 분류에 절대 안 씀 — Codex 가드: game-level ≠ player-level):**

| 신호 | 출처 | 용도 |
|---|---|---|
| HLTB 시간 (Main / Main+Extra / Completionist) | howlongtobeat.com | "이 게임 완주 X시간" 근거 곁들임 |
| Steam **글로벌** 도전과제% | 게임 스토어 도전과제 페이지 | "이 게임 전체 유저 중 Y%만 깼다" 게임페이지용 |

> **오용 금지 재확인:** 문헌의 "5%·11~12% 도전과제 달성률"은 **게임 단위 평균**이다(H 검증 로그). 이걸 "완주자 플레이어 임계값"으로 쓰면 안 됨. 플레이어 완주형 판정은 **S2(본인 달성% 중앙값)** 로만.

## 2. 페르소나 판정 규칙 (임계값 = 🟡 PROVISIONAL, 데모 데이터로 튜닝)

> 규칙은 **임계값(threshold)만** — v0는 ML 클러스터링 불필요(player-typology §5). LLM은 문장화만("이유 번역기"). **아래 숫자는 잠정값**이고, 실제 프로필 채우며 조정한다. 문헌의 game-level 수치를 임계값으로 차용 금지.

| 페르소나 | 트리거 신호 | 잠정 임계값 🟡 |
|---|---|---|
| **수집가 Collector** ← ICP 히어로 | S5 백로그율 高 + 보유수 多 | 백로그율 ≥ 50% & 보유 ≥ 60개 |
| **완주자 Completionist** | S2 본인 달성% 中앙값 高 | 달성% 중앙값 ≥ 65% |
| **헌신형 One-Game Devotee** | S3 최애 집중도 高 | 단일 게임 ≥ 40% 총시간 |
| **잡식가 Omnivore** (~38% 클러스터) | S3 집중도 低 / 다장르 분산 | 상위장르 ≤ 30% & 장르 5+ |
| **경쟁·소셜형 Competitor** | S4 멀티 비중 高 | 멀티 비중 ≥ 55% |

- 복수 트리거 시 **가장 강한 신호(임계 초과폭 큰 것)** 를 1차 라벨, 나머지는 보조 태그.
- 어디에도 안 걸리면 → **"미분류"** 로 기록(= 5신호로 이 사람은 안 잡힌다 = #1 실패 신호).

## 2.5 [초안·2026-07-20] 소프트 코어 모델 — 판단 근거 (⚠️ 조사·분석·연구 후 확정)

> **배경:** 아키타입을 넓이×깊이 2×2 하드 격자에서 **신호 정렬 소프트 코어 5종**으로 전환 결정(**A**, 2026-07-20 — GPT-5.6 Pro·UX·도메인·design 3소스 종합). 출력 = 하드 라벨 1개가 아니라 **코어 + 강도% + 보조 태그 + 개인 신호 근거**.
> **지위:** 아래는 판단 근거 **초안**이다. **② 장르→코어 매핑 조사**와 **연구(신호 분리도·재현성 §4 실투입)** 전에는 §2 본 규칙으로 승격하지 않는다. 임계값 전부 `[가정]`.

**코어별 판단 근거 (단일 vs 복합):**

| 코어 | 판단 근거 | 유형 | [초안] 임계값·비고 |
|---|---|---|---|
| 완주자 | S2 달성% 중앙값 | **단일** | ≥65% (§2 유지) |
| 잡식가 | S3 장르 넓이(엔트로피↑) | **단일** | 상위장르 ≤30% & 장르 5+ |
| 수집가 | S5 백로그율 | **단일** | ≥50% & 보유 ≥60 |
| 헌신형 | ⚠️ **신호 귀속 미정** — S1(상대적 헌신도) vs S3(최애 집중도) | 단일(정의 필요) | 단일게임 ≥40%? — S1/S3 중복 검증 필요 |
| 경쟁소셜형 | **복합: S4 멀티비중 × 장르(경쟁 태그)** | **복합** | S4 단독 불가 — 협동(co-op) 오분류 |

**핵심 열린 항목 (연구로 닫을 것):**
1. **경쟁소셜형 = 복합신호.** S4 멀티비중만으론 협동·경쟁이 뭉개진다 → 경쟁 장르 태그(대전격투·FPS경쟁·MOBA·배틀로얄·히어로슈터)와 교차해야 성립. `[미정: 경쟁형 ↔ 협동소셜형으로 코어를 분리할지 — 신호가 갈라주면 5→6]`
2. **S3 = 공유 기반(substrate), 단일 코어 전용 신호 아님.** 잡식가 넓이 + 경쟁 태그 + 헌신형 몰린 장르를 동시에 먹인다 → 신호 직교성 깨짐(GPT "축 중복성·신호 분리도" 검증항목과 직결).
3. **헌신형 신호 귀속** — 기존 §2 = S3, GPT = S1. S1(상대 헌신도)·S3(집중도) 상관 확인 후 하나로 확정.
4. **장르→코어 매핑 미작성** — 12대륙 장르 각각이 어느 코어에 신호를 주는지 표 필요(②, Steam 태그 taxonomy 접지 후).

→ 이 초안은 **②(장르 매핑) + §4 프로필 실투입 + 신호 분리도·재현성 연구** 후 §2 본 규칙으로 승격한다.

## 3. 근거 규칙 (발화 예시 = R1/R3/R4, 개인 데이터 인용형)

> 규칙이 트리거되면 LLM이 문장화. **반드시 이 사람의 신호값을 인용**하고 신호를 안 넘어야 함(넘으면 = 설명극장 = #5 실패).

| 규칙 | 트리거 | 발화 템플릿 (신호 인용 필수) |
|---|---|---|
| **R1 · 완주 성향** | S2 高 + 후보가 HLTB 짧음 | "너는 시작한 게임 달성% 중앙값이 **{S2}%** — 끝까지 미는 편. 이 게임은 완주 **{HLTB}h**라 네 페이스에 맞음." |
| **R3 · 되살리기** | 후보를 과거 플레이 후 중단(진행 미완) + 최근 인접장르 활동 | "너 이거 **{시간}h** 하다 멈췄고(달성 **{%}**), 최근 **{인접게임}** 을 즐김 → 지금 이어서 완주각." |
| **R4 · 장르 인접·미개봉** | S3 상위장르 + 보유했지만 0시간(S5) 후보 | "네 시간의 **{S3}%** 가 **{장르}**. 근데 이 **{장르}** 게임을 사놓고 **0h** — 다음 픽 1순위." |

**설명극장 차단 체크(#5):** 발화가 (a) 프로필에 실재하는 숫자를 인용했나? (b) 그 숫자가 뒷받침하는 것 이상을 주장했나? → (a) 아니오 or (b) 예 = **틀림**.
