# LMS Assignment Workspace

This workspace turns a future product idea and design into a deliberately small, submit-ready course mock. It is not a copy of the course mini-Notion project and it is not automatically the production project.

Start with [PRD intake](specs/PRD-INTAKE.md), decide the track in [project tracks](docs/PROJECT-TRACKS.md), then follow the [SDD workflow](docs/SDD-WORKFLOW.md) before implementation. The course requirements are recorded in [assignment map](specs/ASSIGNMENT-MAP.md).

## Operating rules

- Build one core user flow before optional features.
- A course mock may use seeded data or a lightweight backend when that is sufficient for the stated assignment. It must say so explicitly.
- Never place tokens, cookies, passwords, OAuth secrets, or real `.env` files in Git or handoffs.
- Follow [handoff policy](docs/HANDOFF.md) whenever work pauses or ownership changes.
- Record each external tool or account in the [access register](docs/ACCESS-REGISTER.md).
