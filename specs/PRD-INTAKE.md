## SDD output after intake

The coordinator creates only these four artifacts before implementation:

1. `SPEC.md` — one flow, functional requirements, non-goals, acceptance criteria.
2. `DESIGN.md` — supplied design references and the minimum component list.
3. `TASKS.md` — tasks no larger than 90 minutes, dependencies, owner, and verification.
4. `SUBMISSION.md` — assignment mapping, deploy/PR target, evidence, and commit SHA placeholders.
